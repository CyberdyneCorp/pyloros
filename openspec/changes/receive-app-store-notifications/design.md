Authenticate the envelope and nested transaction and renewal records before opening a database transaction. Check the bundle, environment, production application ID and original transaction identity. Resolve the owner through a prior purchase claim. Record the delivery and entitlement change together, retaining unresolved mappings for later redelivery. Serialize competing updates by original transaction and deduplicate by notification UUID.

A billing-retry renewal can extend access beyond the transaction's original expiry. A grant that carries a revocation, has already expired, or would undo a newer recorded entitlement is acknowledged without changing access. Only an App Store entitlement for the matched owner and original transaction can be revoked. Signature failures return HTTP 400. An unavailable certificate status service or required hook dispatcher returns HTTP 503 so the delivery can be retried.
