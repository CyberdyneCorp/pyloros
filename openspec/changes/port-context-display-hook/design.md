## Manual execution

The guest needs the received order of object members at every depth. Decode repeated names using the last value and the first insertion position. Render strings and scalar values using the service's existing compatibility formatting where applicable. Apply the output limit after rendering and appending the newline.

## Queued registration

PostgreSQL JSONB retains values and can reorder object keys. Local tests compared the original source's printed registration context with the event bytes returned by a WebAssembly echo component. Both privacy settings exposed an ordering difference. Deliver registration fields in source order after applying enqueue-time and execution-time privacy constraints. An older queued event may already have been redacted. Render only fields still present and permitted when the worker claims the delivery.

Keep the existing hook ABI. A manual caller can supply registration-shaped input in any order, so the guest must never infer queued registration ordering from the presence of event fields. Ownership of the queued order belongs to the producer or delivery adapter.
