Authenticate the Google ID token against the configured push audience and verified service account using rotating Google keys. Check the application ID before using the purchase token. Query Play for subscription state, including on delayed notifications. A cancellation may retain access through the paid period. Recover the purchased product from Play when the notification omits its identifier. Serialize updates for a purchase, and commit delivery history in the same transaction as the entitlement. Keep provider outages retryable.

Purchase validation and notifications share a per-token PostgreSQL transaction lock. Both readers fetch store state after obtaining the lock. A per-process limit bounds the database connections held during provider calls. An unresolved product or owner records a deferred delivery for later resubmission. When a subscription contains several current products, use a matching product identifier if supplied, otherwise defer the ambiguous update.
