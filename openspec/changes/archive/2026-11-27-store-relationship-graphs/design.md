Use the registry row UUID as the graph owner. A model row owns two edge tables. A user edge references the account UUID directly so account deletion removes it. An object edge identifies another product object in the same namespace. Composite primary keys support traversal by owner, object and relation. A separate user index supports account cleanup. Bound the encoded size of indexed text so supported keys fit PostgreSQL B-tree entries. Type and relation names can occupy up to 128 UTF-8 bytes each, and object identifiers up to 512 bytes each. Identifiers use deterministic, case-sensitive comparison.
