The handler receives a filtered event encoded as JSON and returns a string for successful output or an error string. Its versioned WIT interface is the ABI identifier. In the first profile the host supplies no imports. Internally linked modules may import from each other. The endpoint reads at most 4 MiB, validates component and core function bodies on a bounded blocking worker, and checks the exported interface signature. Inspection neither instantiates a guest nor writes a hook record.
