Keep provider execution, persisted user metadata and the operator audit distinguishable. The local provider maintains process-local token identifiers and status. The deployed provider uses the identity contract and an empty email argument when minting. Expose the provider outcome and record the operator action for completed attempts.

A deployed identity provider serializes pending transaction preparation across requests. A settings reload gives new requests their own provider instance. A pending RPC leaves the user record available for edits. The completed retry writes the metadata snapshot it loaded before calling the provider. This can overwrite a concurrent metadata edit.
